- Fail ทั้ง 2 กรณีเป็นปัญหาข้อมูลในฐานข้อมูลใช้งาน ไม่ใช่โค้ด: OP-03 ประกาศ 12 รายการไม่มีผู้แจ้ง และ OP-04 ไม่มีบัญชีเจ้าหน้าที่/ผู้ดูแลที่เปิดใช้งาน
- Blocked / Not Run คือกรณีที่ต้องใช้ production, บัญชี Google จริง, อีเมลจริง หรือผู้ทดสอบที่เป็นคน และ 2 กรณีที่ถูกข้ามบน Windows (symlink, โมเดล AI จริงแบบเลือกเปิด)
- เทียบกับเอกสารเดิม: 17 กรณีที่เคย Fail ตอนนี้ผ่านแล้ว

### เดินตามคู่มือผู้ใช้ (19 ขั้นตอน)

Pass 16, Fail 2, Not Run 1 และพบคู่มือไม่ตรงหน้าจอ 9 จุด

- Fail: ฟอร์มเพิ่มจุดรับฝากไม่มีแผนที่ตามที่คู่มือบอก และการสลับภาษาตามคู่มือทำให้ค่าในฟอร์มหาย
- ไม่ตรง: ชื่อปุ่มหลายจุด, คู่มือให้กรอกรหัสนิสิต/ชื่อตอนสมัครแต่หน้าจอไม่มี, ปุ่มภาษาอยู่ในหน้าโปรไฟล์ไม่ใช่มุมบนขวา

### ข้อบกพร่อง (ชีต Bug Report)

รวม 14 รายการ: เปิดอยู่ 11 (สูง 3, กลาง 3, ต่ำ 5) และแก้แล้วในโค้ดที่เครื่องผู้ทดสอบแต่ยังไม่ merge 3 รายการ

| ระดับ | รายการ |
|---|---|
| สูง | ประกาศในฐานใช้งานไม่มีผู้แจ้ง, ไม่มีบัญชีเจ้าหน้าที่/ผู้ดูแลและจุดรับฝาก, ยังไม่ตั้งผู้ควบคุมข้อมูล (PDPA) |
| กลาง | สีตัวอักษรหน้ารายละเอียดต่ำกว่า WCAG AA, ฟอร์มเพิ่มจุดฝากไม่มีแผนที่, สลับภาษาแล้วค่าในฟอร์มหาย |
| ต่ำ | อัปโหลดรูปผิดฟิลด์ได้ 500, อักขระ % _ ในการค้นหา, URL ที่ไม่มีแสดงหน้าว่าง, คู่มือไม่ตรงหน้าจอ, เครื่องมือ auto-test รายงาน PostgreSQL ผิด |

### ความครอบคลุมของข้อกำหนด (ชีต Traceability Matrix)

ทุกข้อกำหนดมี test case อย่างน้อย 2 กรณี ข้อที่มีกรณีไม่ผ่าน (FR-02, FR-03, FR-04, FR-14) มาจากปัญหาข้อมูลในฐานใช้งาน และ NFR-Performance ยังครอบคลุมน้อย การจับคู่ทำจากชื่อ test และไฟล์ทดสอบ เพราะเอกสาร TEST_CASES ไม่ได้ระบุ requirement
