## สรุปผล

- Test cases ตามเอกสาร 436 กรณี: Pass 424, Fail 2, Blocked 5, Not Run 5
  - Fail ทั้ง 2 กรณีเป็นปัญหาข้อมูลในฐานข้อมูลใช้งาน (ประกาศไม่มีผู้แจ้ง, ไม่มีบัญชีเจ้าหน้าที่/ผู้ดูแลที่เปิดใช้)
  - Blocked / Not Run คือกรณีที่ต้องใช้ production, บัญชี Google จริง, อีเมลจริง หรือผู้ทดสอบที่เป็นคน
- เดินตามคู่มือผู้ใช้ 19 ขั้นตอน: Pass 16, Fail 2, Not Run 1 และพบคู่มือไม่ตรงหน้าจอ 9 จุด

## วิธีทดสอบและข้อมูล

ใช้ฐานข้อมูลทดสอบแยก (PGlite และ PostgreSQL ฐานชั่วคราวที่ลบหลังจบ) บัญชีสังเคราะห์ และดักอีเมลไว้ไม่ส่งจริง การตรวจฐานข้อมูลใช้งานทำแบบอ่านอย่างเดียว และรายงานเฉพาะยอดรวม ไฟล์ใน repo นี้ไม่มีข้อมูลส่วนบุคคลจริง
