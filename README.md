- เทียบกับเอกสารเดิม: 17 กรณีที่เคย Fail ตอนนี้ผ่านแล้ว

### เดินตามคู่มือผู้ใช้ (19 ขั้นตอน)

Pass 16, Fail 2, Not Run 1 และพบคู่มือไม่ตรงหน้าจอ 9 จุด

- Fail: ฟอร์มเพิ่มจุดรับฝากไม่มีแผนที่ตามที่คู่มือบอก และการสลับภาษาตามคู่มือทำให้ค่าในฟอร์มหาย
- ไม่ตรง: ชื่อปุ่มหลายจุด, คู่มือให้กรอกรหัสนิสิต/ชื่อตอนสมัครแต่หน้าจอไม่มี, ปุ่มภาษาอยู่ในหน้าโปรไฟล์ไม่ใช่มุมบนขวา

## การดาวน์โหลดและเปิดไฟล์ Excel

1. กดที่ชื่อไฟล์ `FOUNDLOST_Test_Results_2026-10-25.xlsx` แล้วกดปุ่ม **Download** (ลูกศรลง มุมขวา) — GitHub แสดงตัวอย่างไฟล์ Excel บนเว็บไม่ได้
2. ไฟล์ที่ดาวน์โหลดจะเปิดใน Protected View ตัวเลขสรุปบันทึกไว้ในไฟล์แล้วจึงอ่านได้ทันที กด “เปิดใช้งานการแก้ไข” เมื่อต้องการกรอกหรือแก้ผล

## วิธีทดสอบและข้อมูล

ใช้ฐานข้อมูลทดสอบแยก (PGlite และ PostgreSQL ฐานชั่วคราวที่ลบหลังจบ) บัญชีสังเคราะห์ และดักอีเมลไว้ไม่ส่งจริง การตรวจฐานข้อมูลใช้งานทำแบบอ่านอย่างเดียว และรายงานเฉพาะยอดรวม ไฟล์ใน repo นี้ไม่มีข้อมูลส่วนบุคคลจริง
